# HOW TO COMPILE AND RUN THIS CODE

> Notice: Make sure that you are at the folder `/PhamAnhKhoi_ITCSIU23018_Lab2/`.
> 
> For example: `E:\ForCoding\Artificial-Intelligent-Lab\PhamAnhKhoi_ITCSIU23018_Lab2>`

## Setting Up Environment
The python version is 3.9.x, so you can choose any way to create a virtual environment with python 3.9. In this case, I will use conda.
```bash
conda create -n lab2 python=3.9
```

Then type these command into the terminal
```bash
conda activate lab2
pip install "numpy>=2.0.2" "ipython>=8.18.1"
```

## Run the code
Change directory into `/Lab2`. Then type
```bash
python run_lab2.py
```
