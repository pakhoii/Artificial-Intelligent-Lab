# Setup the Environment
Type in this command to create the environment for this project
```bash
uv sync
```
If you don't have uv, then install it via this [link](https://docs.astral.sh/uv/getting-started/installation/)

Then, activate the environment
```bash
source .venv/bin/activate # For Linux and MacOS
.venv/Scripts/Activate.ps1 # For Windows Powershell
```
